# 瑞丽丝 P0 v0.7.1a · Stage 2C 原型说明

> 基准日期：2026-08-18  
> 实现事实源：`../06_开发资料/原型源码/public/prototype.html`

## 当前阶段

当前交付是可运行的网页体验原型，用于验证“首次关系闭环 + 长期桌面生活态 + 轻量聊天 + 协作 + 专注 + 三场景切换”。它已经跨过静态概念稿阶段，但不等于真实 Windows 客户端、真实 AI 或真实长期记忆系统。

## PT-01 至 PT-11 唯一状态定义

| 状态 | 当前含义 | 核心证明 |
|---|---|---|
| PT-01 | 建立现实锚点 | 首次启动像进入她的世界，而不是软件首页 |
| PT-02 | 初次进入居所 | 先看到她生活，再看到服务入口 |
| PT-03 | 瑞丽丝注意到用户 | 问候发生在自主行为之后 |
| PT-04 | 初次交流 | 只解释名字、深穹与现实锚点 |
| PT-05 | 留下称呼 | 可跳过，不要求真实姓名 |
| PT-06 | 选择共同物品 | 第一次共同决定会影响后续 |
| PT-07 | 物品进入居所 | 场景变化并写入共同记忆 |
| PT-08 | 日常共处 | 不聊天也能共处，映射长期 LIFE |
| PT-09 | 情境对话 | 底部轻量自由输入，场景仍是主体 |
| PT-10 | 用户离开 | 保存离开时间、活动与恢复点 |
| PT-11 | 第二次回来 | 以具体变化和记忆证明连续存在 |

旧文档中“PT-04 称呼、PT-05 物品选择、PT-06 物品落位、PT-07 日常、PT-08 靠近、PT-10 共同活动”的定义已经废止，不再用于当前版本。

## 长期桌面状态

- `LIFE`：默认生活态，场景与瑞丽丝是视觉主体。
- `CHAT`：轻量陪伴输入，关闭后返回原生活快照。
- `ASSIST_INPUT / RUNNING / RESULT`：协作任务输入、执行和结果三个互斥状态。
- `FOCUS_SETUP / RUNNING / COMPLETE`：陪伴式专注设置、运行和完成。
- `SCENE_SWITCH`：三场景轻量选择抽屉。

进入临时状态前保存 `previousScene`、`previousCharacterState`、`previousActivity` 和 `previousMotionLevel`，退出时恢复。

## 场景角色

- 月海花园：主场景，承担相遇、共同物品和长期生活。
- 风眠浮原：首个解锁场景，承担白昼共处。
- 云上列车终点站：事件场景，承担离开、归来和关系节点。

v0.7.1a 不再同时维护一个未接入的独立室内“第一锚居”作为当前场景。未来若恢复，应作为新版本决策，不得与当前场景定义并存。

## Stage 2C 已实现

- 三场景主题令牌和双背景交叉淡化。
- 月海花园：月光、水面、灯光和低频花瓣。
- 风眠浮原：云雾、局部光线、草地光影和低频树叶。
- 云上列车：远景云雾、站台薄雾、灯光辉光和低频远方光点。
- 单一环境容器、统一生命周期、统一 motion factor 与 reduced-motion 支持。

## 尚未完成

- 正式人物图、动作和人物身份接入。
- Stage 2D：LIFE / CHAT / ASSIST / FOCUS 正式动效强度映射、页面隐藏时的统一暂停、最终大屏比例优化。
- PT-12 深穹事件、PT-13 隐私管理、PT-14 记忆管理。
- 真实模型、真实文件解析、当前窗口读取和真实桌面权限。
- Windows 桌面壳、系统休眠恢复、多屏和低配机验证。
- 5 至 8 名种子用户理解与回访测试。

- 当前单文件始终使用稳定文件名 `瑞丽丝交互原型.html`，由构建脚本覆盖生成，避免多个“最新版”并存。
