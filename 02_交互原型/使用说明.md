# 瑞丽丝交互原型使用说明

> 当前版本：P0 v0.7.1a · Stage 2C

## 直接查看

双击 `瑞丽丝交互原型.html` 即可运行，不需要安装依赖。

- 默认进入展示模式。
- 在地址末尾添加 `?review=1` 可开启评审模式。
- 评审模式用于跳转状态和查看验收重点，不属于正式用户界面。

## 当前包含

- PT-01 至 PT-11 首次关系闭环。
- LIFE、CHAT、ASSIST、FOCUS 和 SCENE_SWITCH 长期桌面状态。
- 月海花园、风眠浮原、云上列车终点站三场景。
- Stage 2C 三场景主题、交叉淡化和克制环境呼吸效果。
- localStorage 状态保存、任务完成后的生活快照恢复。

## 重要边界

- 人物仍是 CSS 布局占位，不是正式人物资产。
- 会议整理使用原型内置演示数据，不调用真实模型。
- 当前窗口、文件和权限入口只演示交互逻辑，不代表真实桌面能力。
- 这是网页体验原型，不是 Windows 桌面客户端。
