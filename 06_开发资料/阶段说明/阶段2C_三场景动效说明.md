任一时刻只激活当前场景对应的一个 `scene-ambient-group`。环境容器始终只有一份，所有层均为 `pointer-events: none`、`aria-hidden="true"`，不参与布局。

## 风眠浮原效果

- 两层低透明度云海柔雾：只表达方向与空气层次，不声称原图云朵真实移动。
- 白昼局部光线呼吸：只作用于环境遮罩，不修改整张背景 brightness。
- 草地区域方向性光影：通过局部蒙版与宽幅渐变表达风感，不做真实草浪。
- 低频前景树叶：每次 1 片，极少数 2 片，同时最多 3 片。

## 云上列车效果

- 两层低透明度远景云雾：缓慢、不同速率移动，不移动列车本体。
- 站台边缘薄雾：限定在站台与云海交界区域。
- 四处非同步暖色辉光：只叠加在主要灯光区域，不声称逐灯控制。
- 远方低频光点：同时最多 1 个，只在远景轨道与云层区域出现。

## 场景配置与生命周期

场景通过 `data-ambient-scene` 与统一 `ambientGroups` 映射关联。`applySceneTheme()` 仍由阶段 2A 的双背景交叉淡化流程调用，随后统一进入 `syncSceneAmbient()`：

1. 激活当前场景的唯一环境组。
2. 停止并清理三个场景的旧粒子与旧定时器。
3. 仅为当前场景注册一个低频偶发事件定时器。
4. 切回场景时复用原有 DOM，不重复创建容器或注册全局监听。

## Motion factor 复用

三个场景共同读取：

```css
--motion-factor: 1;
```

内部验证接口仍为：

```js
window.__ruilisiAmbient.setMotionFactor(value)
```

已验证 `1 / 0.70 / 0.40 / 0.25 / 0`。强度下降时，位移、透明度变化与粒子生成频率同步降低；值为 `0` 时隐藏环境动态并清理全部粒子和定时器。本阶段没有正式绑定产品状态。

## 清理方式

- 花瓣、树叶和远方光点均在动画结束后移除。
- 每个节点都有兜底清理计时器，避免 `animationend` 未触发时残留。
- 切换场景、factor 设为 0 或进入减少动态模式时，立即清理相关定时器和粒子节点。
- 每个场景只允许一个低频生成定时器。

## 已知限制

- 当前 Playwright 环境缺少本地 FFmpeg，未生成视频；按要求提供 0 秒、4 秒、8 秒连续帧、偶发粒子可见帧，并额外提供 GIF 动态预览。
- 背景是完整静态图，当前效果只是环境遮罩、局部辉光和前景粒子，不代表真实树冠、草叶、云层或列车运动。
- 三个场景的环境呼吸循环已统一调整为 3 至 5 秒；花瓣、树叶和远方光点仍保持较慢的独立移动时长，避免场景显得急促。
- 没有进入阶段 2D：尚未绑定状态强度、页面隐藏暂停和最终大屏比例优化。
